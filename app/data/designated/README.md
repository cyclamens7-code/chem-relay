# 지정물질 목록 (CAS 자동 대조용)

이 폴더에 지정물질 고시 목록을 JSON으로 넣으면, 서버가 CAS로 대조해
콘솔의 "지정물질 현황"에 자동 표시합니다. 파일을 추가/교체만 하면 되고
코드 수정은 필요 없습니다. (파일명은 자유, 확장자 .json)

## 형식 (둘 중 아무거나)

방법 1) CAS 목록만:
{
  "label": "제한물질",
  "source": "환경부고시 제2023-000호 (제한물질·금지물질)",
  "cas": ["50-00-0", "71-43-2", "108-95-2"]
}

방법 2) CAS별 비고/조건까지:
{
  "label": "사고대비물질",
  "source": "화학물질관리법 사고대비물질 지정 고시",
  "items": {
    "50-00-0": "지정수량 000kg",
    "108-95-2": ""
  }
}

## 넣으면 좋은 고시 (label 예시)
- 제한물질 / 금지물질
- 사고대비물질
- 중점관리물질
- 유독물질
- 등록대상기존화학물질
- 허가물질

## 만드는 법
각 고시의 별표(엑셀/hwpx)에서 CAS 열만 뽑아 위 형식으로 저장하면 됩니다.
엑셀을 채팅에 올려주시면 이 형식으로 변환해 드립니다.
